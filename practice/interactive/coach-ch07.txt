K146 第 7 章互動演練：Hermes 與 OpenClaw 當員工，客戶既有的代理能不能進組織圖（教練稿）

【第 1 步：adapter，控制層和 runtime 之間的橋】
第七章回答一個客戶問題：我的 Hermes 能坐進組織圖嗎？第一步先看 adapter 在做什麼。控制層這邊有角色 Researcher、目標鏈和五十美元的預算上限；adapter 每次心跳把任務交給 runtime，再把結果、token、成本和 session 交回控制層。畫面上跑了三次心跳，成本分別是二點一三、三點三三、一點九六美元，累計七點四二美元，而 session 三次都是 s 零零一，代表對話一直接得上。目的，是記住選哪個 runtime，是角色定好之後的人事決定。

【第 2 步：狀態標籤，像讀合約一樣讀】
第二步把十月二十日文件的狀態表放上來：Claude Code、Codex、Hermes 是 Selectable，native runner 是 Experimental，OpenClaw gateway、Process、HTTP 是 Coming soon，ACPX Local 已經 Retired。接著檢查六句業務說法，例如你的 OpenClaw 直接插上就能用，被標成過度承諾。結果六句裡有五句不能對客戶這樣說，連 Claude Code 支援這句，也因為沒寫日期被標出來。目的，是養成每句話都附日期和原文標籤的習慣。

【第 3 步：成本回報，看不見的花費擋不住】
第三步，三個角色各排二十次執行，上限都是五十美元。Researcher 每次三美元，第十七次被 Paperclip 上限擋下；Writer 每次二點五，剛好跑滿二十次花五十。Poller 是自寫輪詢腳本，不回報成本，紀錄上是零，實際卻花了八十，超過上限三十，上限形同虛設。補救是在供應商端設四十美元限額，這樣它在第十一次停下，並且在 Blueprint 寫明這個角色靠供應商限額。目的，是明白沒有成本回報的 runtime，就是沒有天花板的角色。

【第 4 步：Hermes 使用前檢查，八項都要過】
第四步用八項檢查表看兩位客戶。客戶 A 的 Hermes 跟 Paperclip 同一台、工具集也縮好了，八項全過，可以由 Hermes 擔任這個角色。客戶 B 的 Hermes 在另一台機器，第一項就不過，答案從可以變成要看情況；另外模型不明、工具集沒縮、成本沒出現、自帶 skill 沒審，總共第一、三、四、六、七項沒過。最後提醒，Hermes 會自己改寫 skill，報告語氣變了可能是它學的。目的，是記住內建只代表連線存在，檢查才決定能不能派它上場。

【第 5 步：OpenClaw 邀請流程與全自動模式】
第五步走一遍 OpenClaw 的四步邀請流程：建立邀請、把提示貼進 OpenClaw、人來核准並發一次性金鑰、最後做冒煙測試。狀態從等待核准，到發出金鑰，中間停在 pairing required 等配對，再到已配對、正式上線。同時記下限制：Paperclip 停機時工作會暫停，而且不支援 skill sync。一次性金鑰和 Hermes 都寫進登記表檔案。最後看全自動模式，讀資料夾和改草稿直接放行，對外寄信和刪除客戶檔案在公司層仍然要等人核准。目的，是明白全自動只關掉工具的詢問，公司規則照樣有效。

【第 6 步：讓真實模型當顧問】
第六步會呼叫模型一次，最多等三分鐘。我們給模型一位客戶：一人顧問公司，Hermes 裝在另一台筆電，每月八個任務，再附上十月二十日的標籤，請它建議要建公司還是用單一代理，並寫給客戶的 adapter 說明、每月數字和重算的觸發條件。這次模型建議單一代理，說明裡有日期、有 Selectable 標籤、也提到要同一台機器；不過它算的單一代理淨值是二百美元，加公司層是一百美元，還把 OpenClaw gateway 誤當成能跨機器接 Hermes 的路線，好在有說它還沒推出。每次結果可能不同，萬一呼叫失敗，下一步會改用內建範例。目的，是拿到一份真實建議，留給下一步驗算。

【第 7 步：用程式驗算單一代理的答案】
第七步不再呼叫模型，先用書裡的假設算一張表：每月八個任務，毛價值二百，單一代理淨一百三十七，加上公司層變成負十三；九個任務才不賠錢，這只是不賠，不代表需要公司；到四十個任務，加公司層也還有六百五十三。接著檢查模型的建議，七項裡過了六項，建議、日期、標籤、同機限制、沒有過度承諾的字眼、觸發條件都有，但數字沒過，因為它沒有扣模型花費和審查時間。目的，是記住誠實的答案要把監督時間算進去，模型算的數字也要驗算。

【第 8 步：總結五個重點】
最後總結這一章的五個重點。第一，adapter 讓客戶信任的代理去填角色，選 runtime 是定好角色後的人事決定。第二，狀態標籤像合約，Coming soon 永遠不說成可用，每句話都附日期。第三，成本要回報上限才有效，不回報的就靠供應商限額。第四，Hermes 內建不等於能用，八項檢查都過才派它上場，OpenClaw 走邀請流程，全自動也越不過公司核准。第五，單一代理有時才是誠實答案，要給客戶重算的觸發條件。畫面最後會確認本章產出的三個檔案都在。目的，是記住撐得過變化的本事，是照實讀、照實說，還附上日期。
